# quick-math

Perform arithmetic calculations and explain the math. Use for any math operations, calculations, or number crunching.

## Instructions

When the user asks for a calculation:

1. **Parse the math request** — Identify the numbers and operations needed.

2. **Perform the calculation** — Use the add_numbers MCP tool for addition. For other operations, calculate and explain.

3. **Show your work** — Present the calculation clearly:
   - "5 + 3 = 8"
   - For complex calculations, break it down step by step

4. **Provide context** — If relevant, explain what the result means or offer related calculations:
   - "That's approximately $X per month"
   - "Would you like me to calculate the percentage?"

5. **Handle errors gracefully** — If the math doesn't make sense, explain why and ask for clarification.
